FAQ 및 협업 문의

제품과 영양정보는 어디에서 가져오나요?

제품 검색은 식품안전나라 품목제조보고를 조회합니다. 식약처 식품영양성분DB에서 품목번호가 한 건으로 일치할 때 대분류와 기준량당 에너지를 표시합니다. 값이 없거나 조회에 실패하면 결과에 사유가 표시됩니다.

검색 결과를 어떻게 좁히나요?

검색 대상을 선택하거나 결과에서 제조사·식품유형을 선택하세요. 보고일자 최신순과 10·30·50개 보기를 사용할 수 있습니다. 원본 조회가 5,000행을 넘으면 검색어를 좁혀 주세요.

연결 진단 열기
판매처 가격과 물가 차트는 어떻게 읽나요?

판매처 공개 페이지에서 확인한 가격과 직접 입력한 견적을 구분해 표시합니다. 같은 기준량의 상품가를 비교하고 배송비·쿠폰·재고는 판매처에서 확인하세요. 물가 차트는 국가데이터처 발표월 기준이며 각 지표의 공식 출처는 원자재 동향 탭에서 열 수 있습니다.

개발자에게 협업 제안

데이터 연동, 판매처 견적 제공, 기능 개선을 제안해 주세요. GitHub 로그인 후 공개 게시되므로 연락처나 거래 조건 등 비공개 정보는 제외해 주세요.
